# Islamic Good Practice

দৈনন্দিন জীবনে ব্যবহৃত ইসলামী দোয়া, যিকির ও গুরুত্বপূর্ণ বাক্যগুলোর একটি সহজ ও সুন্দর সংগ্রহ।

## Features

- বাংলা উচ্চারণ ও অর্থ
- আরবি মূল বাক্য
- কখন ব্যবহার করবেন
- দৈনন্দিন দোয়া ও যিকির
- Search ও Category Filter
- বাংলা ও আরবি আলাদা Copy Button
- Dark Mode
- Mobile Responsive Design
- দ্রুত উপরে ও নিচে যাওয়ার Navigation
- প্রয়োজনীয় কুরআন ও হাদিসের Reference

- HTML5

## Purpose

দৈনন্দিন জীবনে গুরুত্বপূর্ণ ইসলামী দোয়া ও যিকিরগুলো সহজে শেখা, মনে রাখা এবং প্রয়োজনের সময় ব্যবহার করার জন্য এই প্রজেক্টটি তৈরি করা হয়েছে।

> দোয়া ও যিকিরের তথ্য ব্যবহারের আগে নির্ভরযোগ্য আলেম ও মূল ইসলামী উৎসের মাধ্যমে যাচাই করা উত্তম।
